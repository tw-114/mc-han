# mc-han v0.8.0-beta.1 Windows Beta

这是面向普通 Minecraft 整合包玩家的 Windows x64 Beta 预览版。它已
覆盖从选择整合包、复用已有中文、AI 翻译、人工检查到安装和撤销的完整
流程。建议先备份整合包，再进行首次安装。

## 本版能力

- 自动发现、识别和扫描常见启动器中的 Minecraft 整合包
- 按内容类别选择翻译范围，复用官方中文、历史译文和本地缓存
- 支持 DeepSeek、OpenAI 和 OpenAI-compatible 翻译服务
- 提供经济、平衡和高质量方案，以及 Token、费用和时间估算
- 支持代表性试译、结构化反馈规则、暂停继续和局部失败重试
- 记录译文来源，支持增量更新、质量检查、人工编辑和审核
- 生成客户端资源包和服务器配置文件，并可导出 ZIP
- 安装前展示文件变化并自动备份，重启后仍可撤销最近安装
- 支持跟随 Windows 的浅色和深色主题

## 安装

1. 下载 `mc-han-windows-x64-v0.8.0-beta.1.zip`。
2. 完整解压 ZIP，不要直接在压缩包内运行。
3. 启动 `mc-han.exe`，无需另行安装 Python。

`mc-han-windows-x64-v0.8.0-beta.1.sha256` 用于校验下载文件完整性。

## 安全说明

- 不会修改 `mods/*.jar`。
- API Key 使用 Windows 凭据保护；保护不可用时只保留在当前会话。
- 安装会在整合包的 `.mc-han/backups` 下备份被覆盖文件。
- 未识别 Minecraft 版本时，构建会明确提示使用兼容 `pack_format`。
