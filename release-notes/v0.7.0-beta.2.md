# mc-han v0.7.0-beta.2 Windows Beta

这是面向 Windows x64 用户的修复预览版，并非稳定版本。首次处理整合包前，建议先备份整合包目录。

## 本次修复

- 统一当前项目、页面、流程阶段和后台任务状态
- 翻译进行中打开设置后，可返回原翻译页面而不重置流程
- 顶部持续显示当前项目、活动任务和进度
- 防止重复启动扫描、试译、完整翻译或构建任务
- 后台任务失败后立即恢复页面和按钮状态
- 关闭软件时为仍在运行的任务提供明确处理选项

## 已支持

- 整合包检测与扫描分类
- DeepSeek、OpenAI 和 OpenAI-compatible 翻译服务配置
- 小批量试译与完整翻译
- Token 与费用统计
- 译文检查、人工编辑和审核
- 资源包生成与 ZIP 导出
- 安装与撤销安装

无法识别 Minecraft 版本时，构建过程可能使用兼容的默认 `pack_format`，程序会明确显示相应提示。

## 使用方法

1. 下载 `mc-han-windows-x64-v0.7.0-beta.2.zip`。
2. 完整解压 ZIP。
3. 运行解压目录中的 `mc-han.exe`。

本版本不需要安装 Python。mc-han 不会修改 `mods/*.jar`，构建和安装沿用现有备份及回滚流程。

配套的 `mc-han-windows-x64-v0.7.0-beta.2.sha256` 用于校验 ZIP 的 SHA-256：

```powershell
Get-FileHash .\mc-han-windows-x64-v0.7.0-beta.2.zip -Algorithm SHA256
```
