# mc-han v0.7.0-alpha.2 Windows MVP Preview

这是面向 Windows x64 用户的 MVP 预览版，并非稳定版本。处理重要整合包前，建议先备份整合包目录。

## 已支持

- 整合包检测与扫描分类
- DeepSeek、OpenAI 和 OpenAI-compatible 翻译服务配置
- 小批量试译
- 完整翻译
- Token 与费用统计
- 译文检查和人工编辑
- 资源包生成
- ZIP 导出
- 安装与撤销安装

## 使用方法

1. 下载 `mc-han-windows-x64-v0.7.0-alpha.2.zip`。
2. 完整解压 ZIP。
3. 运行解压目录中的 `mc-han.exe`。

本版本不需要安装 Python。mc-han 不会修改 `mods/*.jar`，构建和安装前会沿用现有备份及回滚流程。

配套的 `mc-han-windows-x64-v0.7.0-alpha.2.sha256` 文件用于校验 ZIP 的 SHA-256。可在 PowerShell 中运行：

```powershell
Get-FileHash .\mc-han-windows-x64-v0.7.0-alpha.2.zip -Algorithm SHA256
```
