# mc-han v0.7.0-alpha.1 Windows Preview

这是面向 Windows 用户的早期预览版，不是完整稳定版。欢迎体验新的 PySide6 界面并反馈整合包识别问题。

## 已支持

- PySide6 新界面
- 选择本地 Minecraft 整合包目录
- Minecraft 版本与 Forge、NeoForge、Fabric、Quilt Loader 检测
- 模组数量及可汉化能力检测
- 已有中文资源检测
- 损坏或可疑 JAR 的安全警告展示

## 尚未接入新界面

- 正文扫描
- AI 翻译
- API 费用统计
- 用户纠错学习
- 构建、安装与回滚

这些能力仍保留在旧 CLI 或 Tkinter 界面中，但本预览版的新界面暂未连接它们。

## 使用方法

1. 下载 `mc-han-windows-x64-v0.7.0-alpha.1.zip`。
2. 解压整个压缩包。
3. 运行解压目录中的 `mc-han.exe`。

本版本仅支持 Windows x64，不需要安装 Python。mc-han 不会修改 `mods/*.jar`，检测过程只读取实例元数据和 JAR entry 名称。

配套的 `.sha256` 文件用于校验下载 ZIP 是否完整、是否与发布资产一致。可在 PowerShell 中运行：

```powershell
Get-FileHash .\mc-han-windows-x64-v0.7.0-alpha.1.zip -Algorithm SHA256
```
