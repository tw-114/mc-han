## v0.8.0 发布门槛：完整主题系统

- 设置提供“跟随系统 / 浅色 / 深色”，默认跟随系统
- Windows 应用主题为暗色时使用完整深色主题，亮色时使用完整浅色主题
- 手动主题选择独立持久化；切回跟随系统后重新读取 Windows 主题
- 跟随系统模式在运行时重新获得焦点或打开设置时刷新
- 统一 `ThemeManager` / `ThemePalette` 管理应用级样式，不在页面硬编码主题
- 标题栏、边框、导航、卡片、控件、表格、滚动条、进度条、对话框、
  设置、审阅、构建安装、状态栏和工具提示必须保持同一主题
- 禁止混合标题栏、低对比文字、无法辨认的禁用状态和页面切换闪白
- 切换项目不改变主题；切换主题不重置页面，也不中断后台任务
- Windows EXE 必须在系统亮色和暗色下验收，并验证四种切换路径与重启持久化
- 完成后独立提交：`feat: add system-aware light and dark themes`

## 已完成基线

- `ProjectSession` 保存当前项目、流程阶段和当前页面
- `WorkflowController` 统一页面跳转、设置页往返和活动任务入口
- 活动任务期间阻止重复扫描、试译、完整翻译和构建
- 顶部显示当前项目、活动任务和进度
- 任务失败后恢复页面与按钮状态
- 关闭窗口时不阻塞 Qt 主线程

## 阶段 8 完成内容

- 项目级 `provenance.sqlite3` 记录初始来源、当前来源、Provider、模型、
  规则版本、生成/修改/确认时间、原文 hash、模组制品指纹和更新状态
- 来源区分官方 `zh_cn`、整合包作者、受信资源包、历史项目、本地记忆、
  AI 和人工修改，并使用固定优先级
- JAR 在同一次安全遍历中配对 `en_us` / `zh_cn`，不为已有中文二次扫描
- 只有 mod ID、key、英文原文 hash 和模组制品指纹匹配时复用官方中文
- FTB Quests、KubeJS 和随整合包资源包的成对语言文件可安全复用
- 重扫时现有项目译文和人工工作优先，不被新发现的官方译文覆盖
- 试译、完整翻译、缓存复用和人工审阅更新同一来源记录
- TranslationPlan 单独展示已有中文复用数和历史译文复用数

## 阶段 11 完成内容

- 安装继续复用现有 `build_outputs`、installer、manifest 和 rollback，
  未创建第二套文件安装或回滚后端
- 项目级 `.mc-han/install_history.json` 原子保存安装时间、新增文件、
  覆盖文件、相对备份目录、manifest 和回滚结果
- 历史只保存受验证的相对路径；损坏或越界历史不会提供撤销入口
- 重启并重新选择项目后，可从安装历史恢复撤销入口
- 兼容没有安装历史文件的旧版合法 manifest
- 安装前展示新增、覆盖、备份位置和 `mods/*.jar` 只读说明，并进行确认
- 回滚只恢复 manifest 中被覆盖的文件、移除该次安装新增的文件，
  不触碰其他路径
- 安装历史保存失败时不掩盖已经成功的安装，合法 manifest 仍可恢复
- 最近项目同步显示是否已安装以及是否可撤销
