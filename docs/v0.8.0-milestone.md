- `ProjectSession` 保存当前项目、流程阶段和当前页面
- `WorkflowController` 统一页面跳转、设置页往返和活动任务入口
- 活动任务期间阻止重复扫描、试译、完整翻译和构建
- 顶部显示当前项目、活动任务和进度
- 任务失败后恢复页面与按钮状态
- 关闭窗口时不阻塞 Qt 主线程
