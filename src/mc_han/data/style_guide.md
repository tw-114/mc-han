# mc-han Style Guide

- Translate into natural Simplified Chinese used by Minecraft players.
- Prefer clear explanations over word-for-word translation.
- Keep resource IDs, file paths, JSON keys, tags, placeholders, and code unchanged.
- Keep common mod names in English unless a widely accepted Chinese name exists.
- Preserve Minecraft formatting codes, Markdown structure, GuideME tags, and Patchouli macros.
